# alessiogiorgetta.com

Source for my personal website, served by GitHub Pages.

Plain HTML and CSS. No framework, no build step, no dependencies: edit a file,
commit, push, and the change is live.

| File | What it is |
| --- | --- |
| `index.html` | About and contact |
| `research.html` | Pre-PhD projects |
| `cv.html` | CV as a web page; the PDF is in `assets/` |
| `personal.html` | Elsewhere |
| `style.css` | Every style rule on the site |

Assets live under `assets/`: `figures/` for the graphs on the research page,
`papers/` for PDFs and slides, `personal/` for photographs.

To preview locally, open `index.html` in a browser. There is nothing to install.
